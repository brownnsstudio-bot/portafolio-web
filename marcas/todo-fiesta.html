El concepto

Una marca que celebra, hecha para que cada fiesta se vea increíble.

Todo Fiesta reúne piñatería, juguetería y papelería en una identidad alegre y reconocible. El manual define cómo se usa el logotipo, el color y la tipografía para mantener esa energía festiva consistente en cada aplicación.
